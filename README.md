# Capstone Notes

A read-only web viewer for my capstone research vault, hosted on GitHub Pages
so it's accessible without my laptop running.

## What this is

This is a static snapshot of **Tachylite**, a custom web-based
[Obsidian](https://obsidian.md) vault viewer I built for my capstone project.
The research focuses on galvanic vestibular stimulation (GVS) for balance
augmentation, technical minimalism, and open-source neurotechnology.

## The original app (`server.py`)

The full version is a Python/Flask app that runs locally and provides:

- **Live markdown rendering** with Obsidian-style wikilink support (`[[links]]`)
- **Interactive file tree** with folder expansion and file type icons
- **Built-in PDF viewer** with dark mode, zoom, and page navigation
- **Image viewer** with zoom and transparency grid
- **Knowledge graph** showing connections between notes via wikilinks
- **In-browser editing** with a markdown toolbar (bold, lists, code blocks, etc.)
- **File management** (create, upload, delete notes) with session-based permissions
- **Live reload** that auto-refreshes when files change on disk
- **ZIP export** of the entire vault

## This static version

Since GitHub Pages only serves static files, this version is a frozen snapshot
generated by `build_static.py`. It keeps the full look and feel (dark theme,
sidebar, PDF viewer, graph view) but is read-only. The download button provides
a ZIP of all the vault files.

Built with `python3 build_static.py`, deployed with `./deploy.sh`.
